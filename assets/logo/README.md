# assets/logo

`arasaka-logo.webp` is the **Arasaka logo from _Cyberpunk 2077_**, property of **CD PROJEKT S.A.**
It is included only as part of this **fan-made, non-commercial** tribute, with full credit to
CD PROJEKT RED. It is not covered by this repository's license. See
[CD PROJEKT RED's fan content guidelines](https://www.cdprojektred.com/en/fan-content).
If CD PROJEKT RED asks, it will be removed.

To use a different logo: put your image here (transparent background, PNG or WebP), set `LOGO=`
in `cyberneon.conf` and run `./install.sh` again. Empty `LOGO=` = original CyberNeon emblem.
